## 6. Implement the paper's 13 features

Follow Section 3.2 and Table 2 of the provided paper PDF.

Every headline must produce exactly 13 numerical features, in the following fixed order:

1. `entropy`
2. `lexical_diversity`
3. `dale_chall_readability`
4. `flesch_reading_ease`
5. `stop_word_count`
6. `incorrect_word_count`
7. `difficult_word_count`
8. `lengthy_word_count`
9. `two_letter_word_count`
10. `single_letter_word_count`
11. `verb_count`
12. `adjective_count`
13. `noun_count`

Feature definitions:

**1. Entropy**
- Tokenize the headline into word tokens.
- Calculate each token's frequency probability.
- Compute Shannon entropy: `-sum(p * log2(p))`.
- Return 0 for empty input.

**2. Lexical diversity**
- Number of unique word tokens divided by total word tokens.
- Return 0 when there are no word tokens.

**3. Dale–Chall readability**
- Implement the documented Dale–Chall formula.
- Use a fixed, documented difficult-word vocabulary.
- Document how short headlines and missing sentence boundaries are handled.

**4. Flesch Reading Ease**
- Use the standard formula: `206.835 - 1.015 * (words / sentences) - 84.6 * (syllables / words)`.
- Use a documented syllable-counting implementation.
- Handle headlines with no terminal punctuation consistently.

**5. Stop-word count**
- Count word tokens in a fixed English stop-word list.

**6. Incorrect-word count**
- Count word tokens absent from a fixed, documented English vocabulary.
- Use a reproducible vocabulary source and pin its version.
- Clearly document that proper nouns, slang and valid uncommon words may be counted as unknown.

**7. Difficult-word count**
- Count words absent from a fixed, documented easy-word list.
- Document the source of that list.

**8. Lengthy-word count**
- The paper's table defines this feature as counting words with more than two characters.
- Follow that literal definition for the paper-aligned experiment, even though the feature name suggests a different threshold.
- Explicitly document this discrepancy.

**9. Two-letter-word count**
- Count word tokens with exactly two alphabetic characters.

**10. Single-letter-word count**
- Count word tokens with exactly one alphabetic character.

**11. Verb count**
- Use a documented English part-of-speech tagger.
- Count tokens tagged as verbs.

**12. Adjective count**
- Count tokens tagged as adjectives.

**13. Noun count**
- Count tokens tagged as nouns.

Use a consistent tokenizer and POS tagger. Pin their versions and document how contractions and hyphenated words are handled.

The paper does not uniquely specify every vocabulary, tokenizer and linguistic annotation implementation. Make reasonable, reproducible choices and document them. Do not claim exact reproduction of unspecified details.

Create a single canonical feature-extraction function returning all 13 features in the exact order above.

- Empty strings
- Whitespace-only strings
- Punctuation-only strings
- Short headlines
- Contractions
- Headlines with numbers
- Unknown words
- Ordinary English sentences

All features must be finite numerical values. No NaN or infinity is allowed.
